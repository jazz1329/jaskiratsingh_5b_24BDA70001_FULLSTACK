# 🌱 Spring Boot Experiment 5

A Spring Boot-based web application developed as part of a **Full Stack Development** practical experiment. This project demonstrates the fundamentals of building and running a Java-based backend application using the Spring Boot framework.

---

## 📌 Project Overview

This project focuses on developing a backend application using **Spring Boot** and understanding the basic structure of a modern Java web application.

The application demonstrates how Spring Boot can be used to create a lightweight, configurable, and scalable backend for full-stack applications.

---

## ✨ Features

* 🌱 Spring Boot application
* ☕ Java-based backend
* 🌐 Web application architecture
* 📦 Maven-based dependency management
* ⚙️ Spring Boot auto-configuration
* 🧩 Modular project structure
* 🚀 Embedded server support
* 🛠️ Easy local development and testing

## ⚙️ Prerequisites

Before running the project, make sure the following are installed:

* **Java JDK**
* **Maven**
* **Git**
* **IntelliJ IDEA / Eclipse / VS Code** (optional)

Check Java:

```bash
java -version
```

Check Maven:

```bash
mvn -version
```

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/jazz1329/jaskiratsingh_5b_24BDA70001_FULLSTACK.git
```

### 2. Navigate to the Project

```bash
cd jaskiratsingh_5b_24BDA70001_FULLSTACK
```

### 3. Build the Project

Using Maven:

```bash
mvn clean install
```

### 4. Run the Application

```bash
mvn spring-boot:run
```

Alternatively, run the main Spring Boot application class from your IDE.

---

## 🌐 Application URL

Once the application starts successfully, it can generally be accessed at:
